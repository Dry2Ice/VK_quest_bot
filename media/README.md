Кладите сюда две картинки квеста под именами из config.py:

  captcha.jpg  — капча после сканирования QR2 (CAPTCHA_PHOTO_FILE)
  rebus.jpg    — картинка с ребусом после сканирования QR3 (REBUS_PHOTO_FILE)

При старте бот сам загрузит эти файлы в VK и запомнит готовые attachment-строки
в media_cache.json — заново грузиться будет только изменённый файл. Имена файлов
можно поменять через .env (см. .env.example).

Эта папка не обязана лежать в media_cache.json/git — сам media_cache.json
пересоздаётся автоматически.
